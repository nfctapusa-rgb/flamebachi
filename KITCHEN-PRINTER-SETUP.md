# Flamebachi GoodTable — Printer Setup

## What the owner does
1. Sign in at `https://admin.flamebachi.com`.
2. Open **Printers**.
3. Click **Generate Bridge Token**.
4. Copy the token.
5. On the restaurant Windows computer, install Node.js.
6. In `kitchen-bridge`, copy `.env.example` to `.env`.
7. Set `KITCHEN_BRIDGE_TOKEN` to the copied token.
8. Set `PRINTER_HOST` to the thermal printer's local IP address.
9. Leave `PRINTER_PORT=9100` for standard ESC/POS TCP printers unless the printer uses another port.
10. Run `start-windows.bat`.
11. In Admin → Printers, click **Add Printer** and enter the same printer IP/port.
12. Click **Request Test Print**.
13. If the printer prints the GoodTable test ticket, setup is complete.

## How orders print
Customer website or kiosk → GoodTable order → local Printer Bridge → kitchen printer.

The owner does not manually print each order. The bridge polls the GoodTable backend and acknowledges each successfully printed order so it is not repeatedly printed.

## Security
- The Bridge Token is generated by the owner dashboard and stored with the restaurant printer configuration.
- Keep the bridge `.env` private.
- Never put Clover, Stripe secret keys, or bridge tokens into customer-facing HTML/JavaScript.
- Regenerate the Bridge Token in Admin → Printers if the restaurant computer is replaced or the token is compromised.
