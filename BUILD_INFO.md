# Build info

GoodTable × Flamebachi Owner CRM integration.

The customer website remains the public experience. `admin.flamebachi.com` is the owner workspace on the same Netlify project.

Development access is automatic on the admin hostname for setup. No PIN is required in this build.

Core integrations use the existing Flamebachi Netlify Blobs stores and functions:
- orders
- customers
- menu
- printers
- payments
- analytics
- settings

Clover is intentionally shown as waiting for GoodTable setup until the merchant connection is performed securely.
